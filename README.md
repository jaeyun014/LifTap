# LifTap

Chrome과 Safari 사이에서 현재 창의 탭을 옮기는 macOS 메뉴 막대 앱입니다.

## 빌드 및 실행

macOS 13 이상을 대상으로 빌드합니다. 소스 빌드에는 Swift 6을 포함한 Xcode 또는 Command Line Tools가 필요합니다.

```sh
./Packaging/build-app.sh
open dist/LifTap.app
```

처음 담거나 열 때 macOS가 대상 브라우저의 자동화 권한을 요청할 수 있습니다. 권한은 **시스템 설정 → 개인정보 보호 및 보안 → 자동화**에서 확인할 수 있습니다. 로컬 빌드는 기본적으로 임시 서명(ad-hoc)을 사용합니다. 재빌드 후 macOS가 권한을 다시 물을 수 있으며, 고정된 서명 인증서가 있다면 `LIFTAP_SIGN_IDENTITY`로 지정할 수 있습니다.

## 사용 방법

| 단축키 | 동작 |
| --- | --- |
| `⌃⌥C` | 활성 Chrome 또는 Safari 창의 탭 담기 |
| `⌃⌥V` | 최신 세션을 활성 브라우저의 새 창에서 열기. 다른 앱에 있으면 대상 브라우저를 선택할 수 있습니다. |
| `⌃⌥Space` | 세션 패널 열기 또는 닫기 |

메뉴 막대의 겹친 사각형 아이콘에서도 같은 명령을 실행할 수 있습니다. 다른 앱이나 시스템이 단축키를 사용 중이어서 등록에 실패하면 메뉴에 표시합니다.

패널에는 최신 10개가 보입니다. ↑↓로 이동하고 →로 탭 제목과 URL을 펼치고 ←로 접습니다. Enter는 선택한 세션을 열고 Esc는 패널을 닫습니다. **이전 세션**으로 더 오래된 기록을 열람할 수 있습니다.

세션을 선택하고 목록에서 **Backspace(⌫)**를 누르거나 **세션 삭제…** 버튼을 클릭하면 확인 후 저장 기록을 삭제할 수 있습니다. 현재 브라우저에 열린 탭은 그대로 유지됩니다.

HTTP와 HTTPS 주소를 복원합니다. 담은 창에 웹 주소와 브라우저 전용 주소가 섞여 있으면 둘 다 기록하고 복원할 때 전용 주소를 건너뜁니다. 브라우저가 탭 열기 명령을 받으면 열린 수로 계산합니다. 페이지의 네트워크 로딩은 브라우저에서 진행됩니다.

세션은 `~/Library/Application Support/LifTap/Sessions/`에 개별 JSON 파일로 보관됩니다. LifTap은 세션을 서버로 전송하거나 시스템 클립보드를 사용하지 않습니다.
